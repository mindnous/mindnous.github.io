# Folksagent - Democratize AI Agent.

Folksagent is a platform service that aims to simplify and deploy AI agent or Computer Vision on edge devices (Mini PC / Arm device / laptop / PC). 

---

### This platform is aimed to help:
1. Healthcare with early diagnoses and symptomps, department assignment, and possible solution
2. Babies / kids / toddlers with speech learning platform (english - Indonesia - other language coming soon)
all with the help of on-device (or cloud if necessary) AI Agent.
